\# 🎉 AI Event Planner



An AI-powered event planning web app.



\## Features

\- Secure login/signup (JWT + bcrypt)

\- AI-generated event plans via Groq

\- Save and view past events

\- Modern glassmorphism UI



\## Tech Stack

\- Frontend: HTML, CSS, JavaScript

\- Backend: Node.js, Express

\- AI: Groq API



\## How to Run

1\. cd Backend

2\. npm install

3\. Create .env with GROQ\_API\_KEY, PORT, JWT\_SECRET

4\. npm start

5\. Open Frontend/login.html
